# Паспорт проекта

## Что это за система?
<Эксплуатация сетей газораспределения (далее ЭСГР) служит для учета всех этапов жизненного цикла распределительного газопровода.>

## Технические характеристики
| Параметр | Значение |
|---|---|
| Платформа | 1С:Предприятие 8.3.24 (укажи версию) |
| Режим работы | Клиент-сервер |
| СУБД | MS SQL  |
| Тип конфигурации | Полностью собственная разработка |

## Ключевые подсистемы (6 штук)
1. <Газопроводы> — <учет линейных частей газораспределительной сети>
2. <ПРГ - пункты редуцирования газа> — <учет пунктов редуцирования газа>
3. <ЭХЗ - электро-хим защита> — <учет систем и объектов электро-хим. защиты>

## Интеграции (кратко)
*   **SQL-БД** — прямое чтение/запись через ADO (подробнее в разделе Интеграции).
*   **ГИС-Карта** — самописная интеграция.
*   **Другие ИБ** — обмен по HTTPS-сервисам.
